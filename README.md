# AccessibilityIssuesExamples

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 22.0.8.

This applications aims to show a side by side comparison of good and bad accessibility practices both in UI Design and Code, how issues in code can affect accessibility and usability.
Also, this project is a test project for AI augmented development by doing base implementations with ai and applying manual adjustments, fixes and content.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
