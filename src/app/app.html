Accessibility Coding-Beispiele

Barrieren verstecken sich in den kleinsten Ecken und können schnell übersehen werden. Wenn man es aber erstmal weiß, kann man grobe Fehler auch schnell vermeiden. Folgende Beispiele zeigen verschiedene Probleme im Code und wie sie behoben werden können.

Falsch

  • Button fokussieren
  • Von Screen-Reader vorlesen lassen

Richtig

  • Styles müssen selbst gebaut werden
  • Button bleibt fokussierbar
